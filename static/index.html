    What can I use as a source?
    • rtsp://… – most IP / CCTV cameras (check your camera's manual for the stream path)
    • http://…/video.mjpg – MJPEG streams
    • http://…/snapshot.jpg – a still image URL, fetched each check
    • 0 – a webcam plugged into this computer
    • /path/to/video.mp4 – a recorded video, looped
    • demo – a simulated lot, with 3 weeks of sample history

    Raise sensitivity if parked cars are being missed; lower it if empty spaces show as taken.
